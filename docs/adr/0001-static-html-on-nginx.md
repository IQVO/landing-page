# ADR 0001: Static HTML on nginx; no Docusaurus, no framework, no GitHub Pages

Status: accepted. Date: 2026-11-02.

## Context

IQVO needs a public landing page. Its job is different from the documentation site: win attention, state plainly that this is a
Domain-Driven Design study and an experiment in AI agents, memory and harness engineering across different LLMs, and send readers
to the documentation and GitHub. The fleet's documentation is Docusaurus on GitHub Pages (`warehouse-docs`). The owner decided this
page will be hosted on nginx, not GitHub, and must not be Docusaurus.

## Decision

- The page is hand-written static HTML, one CSS file and four small JS files. No framework, no bundler, no runtime dependency.
- Node is used only for build-time scripts (`collect-facts`, `build`, `check`) that use the standard library alone.
- It is served by nginx (container image on `nginx-unprivileged`, plus a host-install example). CI verifies; nothing publishes to
  GitHub Pages.
- Fonts are self-hosted (three families, latin subset, SIL OFL). The page makes no third-party request, which lets the CSP be
  `default-src 'none'` plus `'self'` for script, style, image, font and connect.
- Brand: the IQVO logo from the organisation avatar (transparent lockup, vectorised mark) and a palette sampled from it. One signal
  colour (amber) marks "human" and "the variable".
- The documentation stays where it is. This page links to it through `DOCS_URL` and never copies it.

## Consequences

- Fast and cheap to serve (about 31 KiB of HTML+CSS+JS gzipped, plus 136 KiB of fonts and the logo), trivially cacheable, nothing to patch at runtime.
- No component library: the markup is conventional and the CSS is one file, so changes are edits, not migrations.
- Content that comes from the repositories is regenerated by a script (ADR 0002) rather than fetched in the browser, so the page keeps
  working with JavaScript disabled and never depends on another service being up.
- The map layout is computed once at fact-collection time, not in the browser. A new context changes `data/facts.json`, not code.
- The vector mark is traced from a 460 px raster: faithful at normal sizes, but replace `iqvo-mark.svg` with the designer's master
  file if one exists.

## Alternatives considered

- Docusaurus (rejected by the owner): right tool for docs, wrong one for a campaign page; it would also couple the page's release to the docs'.
- Astro / Next / Vite: no requirement they would meet that plain files do not, and each adds a toolchain to a page that has none today.
- GitHub Pages (rejected by the owner): the target is nginx.
